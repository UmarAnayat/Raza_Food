### The Idea

> A drinks shop doesn’t pause for bad internet.  
> This app was built for that reality.

**Raza Food Point** is a focused inventory system for beverage retailers.  
It brings stock control, sales recording, supplier lists, and a clear daily view into one reliable mobile experience — designed to keep working when the shop is at its busiest.
